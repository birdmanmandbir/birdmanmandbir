**Currently building:**

- 🕸️ **[Kepos](https://kepos.guion.io)** ([source](https://github.com/LamplitIsles/kepos)) — makes services on another machine feel local, with no stable public IP, account, or virtual subnet required. Approved devices discover a service registry; per-device and per-service allowlists decide what each can open. Protomux channels carry those services over one persistent, authenticated HyperDHT connection, with native Bare clients on Android and macOS.
- 📝 **[FlickNote CLI](https://github.com/guionai/flicknote-cli)** — a local-first second brain for humans and agents. A local daemon owns SQLite and sync; the CLI and MCP server talk to it through a typed Unix-socket API.
- 🧭 **[Organon](https://github.com/tta-lab/organon)** — structure-aware tools that help agents perceive and act on code and the web. Tree-sitter symbol editing, guarded forge operations, small cores, thin adapters.

**Working on:** Kepos-specific forks of `bare-app-kit`, `bare-native`, and `bare-web-kit` — WebView messaging, tray and window lifecycle, external URL handling, deterministic teardown.
